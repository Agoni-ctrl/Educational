## 一、项目概述

### 1.1 创作背景

随着人工智能技术进入教育领域，越来越多的老师开始尝试用 AI 帮忙备课。但市面上常见的 AI 工具大多面向通用办公场景，并不了解一节课是怎么备出来的，往往只能给出几段零散的文字，老师拿到手还得自己重新组织成课件、教案和题目。

备课这件事，本质上是围绕同一个课题反复做几件重复的工作：先想清楚这堂课怎么讲，再动手做课件，接着把教学思路整理成教案，最后还要配一套练习或检测题。这几件事环环相扣，却分散在好几个工具里来回切换，费时又费力。尤其对刚入职、经验还不多的新老师来说，既要把课讲清楚，又要做出像样的课件和教案，负担更重。

我们做这个平台的初衷，就是把这些分散的环节聚到一起：让老师只需要把"上什么课、给谁上"大致说清楚，剩下的整理思路、生成课件、成文、出题，都交给系统自动完成。

### 1.2 作品定位与简介

**作品名称**：知启灵枢——大模型驱动的中小学教师 AI 备课与教学资源创作平台

**一句话概述**：以「AI 备课助手」为核心入口，通过对话式交互准确理解教师需求，一站式自动生成课件、教案、练习与试卷，并提供学情分析能力，把教师从繁重的备课劳动中解放出来，回归教学本身。

**面向对象**：中小学各学科教师，以及教研员、集体备课组长和备课经验不足的新手教师。

**设计理念**：让老师"只动嘴、少动手"。老师在助手里用自然语言把备课想法说清楚，系统就能自己推断出学科、学段和教学重点，再把生成的内容通过「转入生成」一键变成能编辑、能导出的课件和教案，不用把同样的话在表单里再重新填一遍。

### 1.3 核心功能一览

平台围绕「备课、创作、分析」三件事，做了下面这些功能：

| 功能模块    | 它是干什么的                                                             | 我们是怎么做的                                                                                                      |
| ----------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| AI 备课助手 | 老师用对话的方式说出备课需求，就能得到可用的备课思路、教案草稿或出题草稿 | 支持「备课构思 / 教案草稿 / 出题草稿」三种场景，根据学科自动推断学段，回复逐字显示、不干等                          |
| 课件制作    | 一键生成能直接上课用的 PPT 课件                                          | 先按学段匹配模板（小学优先卡通风、初高中用标准模板），老师选好篇幅和风格后，AI 自动往里填教学目标、重难点和章节内容 |
| 教案编写    | 生成结构完整的教案文档                                                   | 老师只填教学目标，AI 补全教学过程、板书、作业等，导出 Word 后可继续修改                                             |
| 课堂练习    | 按知识点和难度出练习题                                                   | 设置难度分层后，AI 生成分层练习题，可用于随堂检测                                                                   |
| 试卷生成    | 针对单元或阶段测试出整套试卷                                             | 按出题方向和难度命制试卷，支持导出                                                                                  |
| 学情分析    | 把学生成绩、参与度等数据画成图表，帮老师看清班级情况                     | 提供能力雷达、成绩趋势、参与度等图表，辅助老师调整教学                                                              |

除了上面这些，平台还有**社区**（和其他老师分享、交流课件教案）和**个人中心**（管理自己生成过的作品），老师做好的资源都能存下来，下次备课直接改一改就能用，不用从头再来。

### 2.2 应用场景

根据备课的完整流程，我们把使用场景归纳为四个典型环节：

- **日常备课**：老师把"上什么课、给哪个年级上"说清楚，系统生成课件和教案，老师在此基础上修改，节省从零整理的时间。这是最主要的使用场景。
- **公开课 / 赛课准备**：老师需要呈现更完整、更美观的教学设计，可用「AI 备课助手」先梳理思路，再生成版式规范的课件和教案，提升呈现效果。
- **随堂检测与阶段测试**：课堂中需要配套练习、单元或阶段测试时，按知识点和难度生成分层题目，避免临时找题、拼题。
- **学情分析与教学调整**：考试或作业后，通过成绩、参与度等图表了解班级整体情况，发现薄弱环节，为下一步教学安排提供依据。

## 三、总体设计

### 3.1 系统架构

平台采用「前后端分离 + 云端大模型」的整体架构，分为四层：

- **前端展示层**：基于 Vue3 的 Web 单页应用，包含首页、AI 备课助手、课件制作、教案编写、练习/试卷、学情分析、社区、个人中心与管理后台等页面。
- **后端服务层**：基于 FastAPI 提供统一 API，负责接收前端请求、调度 AI 生成、管理任务进度、生成并返回文件。
- **AI 能力层**：通过两家大模型服务提供内容生成能力（详见 3.2 技术选型）。
- **数据与文件层**：任务记录持久化到本地 JSON 文件，生成的课件、教案、试卷等文件保存到本地输出目录，供下载与复用。

系统一次「生成课件」的请求流程大致如下：前端把老师填写的课题、学段、教学目标、篇幅等参数发给后端 → 后端调用大模型生成结构化内容 → 后端把内容按模板渲染成 PPT 文件 → 返回下载地址与任务进度给前端展示。

### 3.2 技术选型

**表 3-1　技术选型**

| 层次   | 技术                      | 用途                                     |
| ------ | ------------------------- | ---------------------------------------- |
| 前端   | Vue3 + Vite + Vue Router  | 单页应用与页面路由                       |
| 前端   | TailwindCSS               | 界面样式                                 |
| 前端   | ECharts                   | 学情分析图表（能力雷达、成绩趋势等）     |
| 后端   | Python + FastAPI          | 提供 API 服务（uvicorn 启动，端口 8000） |
| 后端   | python-pptx / python-docx | 生成 PPT 课件与 Word 教案                |
| 大模型 | DeepSeek（deepseek-chat） | 生成课件内容、教案、练习题、试卷         |
| 大模型 | 阿里云百炼 Qwen           | 「AI 备课助手」对话（流式逐字返回）      |
| 存储   | 本地 JSON（tasks.json）   | 任务记录持久化，服务重启不丢失           |

选择这两家大模型的原因：DeepSeek 中文生成质量好、成本低，用于一次性生成结构化的课件/教案/题目；Qwen 对话接口支持流式输出，适合备课助手这类需要逐字显示、实时反馈的对话场景。

### 3.3 创新点

围绕"让老师只动嘴、少动手"的初衷，平台主要有以下几个设计亮点：

- **对话式备课，自动推断学科与学段**：老师不用填一堆表单，只要说出课题（比如"函数的单调性"），AI 助手会自行推断学科、学段和教学重点，直接给出备课思路，而不是反问一堆问题。
- **按学段自动匹配课件模板**：系统会根据学段推荐合适的模板——小学优先匹配卡通风格的精美模板，初高中则用更正式的标准模板，避免"卡通风"误配到高年级课堂。
- **「转入生成」一键落地**：AI 助手里聊出来的备课构思、教案草稿，可以一键转入课件/教案/出题模块，系统自动把对话内容里抽出的教学目标、重难点填进表单，老师不用把同样的话再抄一遍。
- **流式输出，实时反馈**：备课助手的回复逐字实时显示，老师能立刻看到 AI 在"想"，不用对着空白页面干等。
- **所有选项都可自定义**：表单里每个字段都提供"自定义"入口，老师想用自己的说法就自己填，系统严格按老师的输入来生成，而不是替老师做决定。

## 四、核心功能实现

### 4.1 AI 备课助手

AI 备课助手是平台的入口，提供「备课构思」「教案草稿」「出题草稿」三种定向模式和「通用问答」自由对话。

实现上，后端为每种模式预先准备好一套任务指令（如「备课构思」会要求按课型区分结构、按学生层次调整深度），再结合多轮对话历史，调用大模型一次性完成规划。其要点：

- **多轮对话**：前端把整段对话历史发给后端 `/api/chat`，后端在系统提示里拼接「教师已声明的学科、任教年级」画像后交给大模型，保证后面的回复结合前后文，而不是每轮都从零开始。
- **自主推断学科与学段**：系统提示中明确要求"优先从课题推断学科与学段，不要反问"（例如「函数的单调性」直接按高中数学作答）。只有课题确实含糊到无法判断时才简短追问，避免一上来抛一堆问题。
- **流式输出**：后端以 SSE 事件流逐段返回生成内容，前端逐字实时显示，老师能立刻看到 AI 在"想"，不用对着空白页面干等。

### 4.2 课件与教案生成

「AI 备课助手」提供的三种定向模式以【补充：此处可插入架构图/截图，对应助手对话 → 转入生成 → 落地文件】为例，以下两种是内容落地的主要形态：

**课件（PPT）生成**

- 后端按课题、学科、学段、风格、章节大纲调用大模型，按约定格式返回结构化内容（封面、章节分隔、知识点页、对比页、总结页等）。
- 渲染时先按学科/学段匹配模板：小学优先匹配卡通风格的精美模板，初高中用正式的标准模板；精品模板走专门的保版式引擎，只往模板固定槽位填文字，最大限度保留模板排版。
- 章节与篇幅会控制在对应模板的容量范围内，避免生成的页数超出模板能容纳的数量而被截断。

**教案（Word）生成**

- 后端只要求老师填写少量信息（如教学目标），大模型按教案结构自动补全教学过程、板书、作业等内容，再通过文档库生成可编辑的 Word 文档，老师可继续修改。

两类生成都以"任务"方式在后端后台执行：创建任务 → 调用 AI 生成内容 → 渲染文件 → 返回下载地址，进度通过 SSE 实时推给前端展示；任务记录写入本地 JSON 文件，服务重启后依然在。

> 补充：此处可插入「课件制作」「教案编写」界面截图，及一个生成进度展示截图。

### 4.3 练习 / 试卷与学情分析

- **课堂练习**：按课题、难度生成一组分层练习（基础 / 提升 / 拓展），题型含选择、填空、简答，每题附参考答案与考察点，生成页面文件供随堂使用。
- **试卷生成**：按考试范围、难度生成完整试卷，包含选择、填空、解答三部分，每道题标注分值，并提供参考答案与评分标准；支持生成 A/B 两套卷。
- **学情分析**：前端使用图表库将班级成绩、参与度等数据可视化，产出诸如能力雷达、成绩趋势等图表，辅助老师发现薄弱环节、调整教学安排。

> 【待你核对】目前学情分析所需的数据来自前端展示用数据。若希望文档写得更扎实，可补充你实际是否接入了真实成绩数据：可能有而没有，可考虑补一段"数据接入方式"说明；如果只是演示数据，这一句建议改为"以演示数据展示图表效果"，避免评委追问数据来源。

> 补充：此处可插入「课堂练习」「试卷」「学情分析」界面截图。

### 4.4 「转入生成」桥接

为了让在 AI 助手里聊出来的内容能直接落地成文件，平台实现了「转入生成」衔接：老师在助手满意产出后点「转入生成」并选择目标（课件 / 教案 / 出题），前端自动跳到对应的制作页。

由于对话草稿可能很长，跳转时把课题放在页面地址参数、草稿全文放入浏览器临时存储（带 60 秒时效，防止旧内容残留污染表单）。制作页读取后自动从草稿中抽取学科、学段、教学目标、教学重难点等，填入对应表单字段，老师无需把同样的话再抄一遍，稍作确认即可开始生成。
